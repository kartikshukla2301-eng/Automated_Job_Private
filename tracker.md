  **not yet implemented**, plus genuine code-level gaps found while auditing the repo.
- Never touch: `real_submit_gate_enabled`, provider rollout order, database schema (only additive
  migrations allowed), autonomy ceiling rules, LinkedIn L1 cap. These stay locked per `AGENTS.md`/`docs/DECISIONS.md`.
- Every task must be independently verified in this session (tests/lint/build actually run) before
  being marked DONE. If a task can't be verified here (e.g. needs live external credentials), it is
  marked BLOCKED, not DONE, and the reason is stated.
- Docs updated for every DONE task: `PROJECT_CONTEXT.md`, `docs/TASK_TRACKER.md`, `docs/CHANGELOG.md`.
